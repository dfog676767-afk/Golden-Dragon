# The Golden Dragon

A small, choice-driven text adventure. Play as a young dragon, explore the
mountain pass, decide how to help a village, then choose how to face the knight
guarding a legendary hoard.

## Play

Requires Python 3. Run from the repository directory:

```text
python game.py
```

Choose an option by entering its number. Your choices affect whether you can
make peace with the knight or survive the fight. After the story ends, choose
whether to play again or exit.

## Test

Run the game's tests with:

```text
python -m unittest discover -s tests
```
